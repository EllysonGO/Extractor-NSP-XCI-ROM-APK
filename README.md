# Extractor-NSP-XCI-ROM-APK
Esse repositório trata-se de uma inspiração de Recomp do Zelda Breath Of the Wild. Como referência peguei o vídeo do Autoridade Tech que fez um Apk "Próprio" e fez seu Extractor apartir do APK BOTW RECOMP, agora estou criando um Apk separado que vai extrair os arquivos Necessários de qualquer jogo da Nintendo pelo seu próprio celular!
