🌿 Sobre o projeto

O ZeldaRomTool é uma ferramenta desenvolvida para Android, criada com o objetivo de facilitar a extração, organização e gerenciamento de arquivos internos de jogos.

O projeto nasceu da inspiração na lendária franquia The Legend of Zelda, especialmente em sua identidade visual, seu universo e na paixão por explorar cada detalhe dos jogos.

Entretanto, o ZeldaRomTool não foi desenvolvido exclusivamente para jogos da franquia Zelda.

Sua proposta é muito mais abrangente: oferecer uma ferramenta que possa trabalhar com diferentes jogos e formatos de arquivos compatíveis, permitindo que jogadores, entusiastas e desenvolvedores tenham maior controle sobre os conteúdos de suas próprias ROMs.

Zelda foi a inspiração. A exploração de jogos é a missão.

⚔️ Principais funcionalidades

📦 Extração de ROMs

- Leitura de estruturas de arquivos de jogos compatíveis.
- Extração de conteúdos internos.
- Organização dos arquivos extraídos em diretórios.
- Suporte à leitura de estruturas PFS0 e HFS0.
- Processamento de arquivos NSP e XCI compatíveis.

🗂️ Gerenciamento de arquivos

- Organização dos arquivos extraídos.
- Separação dos conteúdos em suas respectivas pastas.
- Gerenciamento dos diretórios de extração.
- Acesso aos arquivos internos dos jogos.

🔍 Análise de conteúdo

- Leitura da estrutura interna das ROMs.
- Identificação de arquivos presentes nos pacotes.
- Visualização de informações dos arquivos encontrados.
- Processamento de estruturas de jogos compatíveis.

🛠️ Sistema e configurações

- Interface nativa para Android.
- Configurações integradas ao aplicativo.
- Estrutura preparada para receber novas funcionalidades.
- Sistema planejado de verificação e atualização de versões.

🔄 Atualizações

O projeto também prevê a implementação de um sistema de atualização integrado ao aplicativo, utilizando as versões publicadas no GitHub como referência para verificar novas versões.

🎮 Não é somente sobre Zelda!

Apesar de carregar Zelda em seu nome, o ZeldaRomTool possui uma proposta que vai além de uma única franquia.

O objetivo é oferecer compatibilidade com diferentes jogos, desde que suas estruturas e formatos sejam suportados pelo sistema de extração.

Entre as franquias que representam o universo de jogos que inspirou e motivou o projeto estão:

- The Legend of Zelda
- Super Mario
- Pokémon
- Metroid
- Animal Crossing
- Fire Emblem
- Xenoblade Chronicles
- Outras franquias e jogos compatíveis.

Importante: a compatibilidade depende dos formatos, estruturas e sistemas de arquivos implementados. A presença de uma franquia nesta lista não significa suporte integral a todos os seus jogos.
